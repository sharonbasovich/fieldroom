# Provenance and license status

Fieldroom was created from scratch in October 2026 as a fictional equipment borrowing frontend. No previously judged project, campus code, campus branding, personal borrower data or real equipment data was reused.

OpenAI Codex assisted visual exploration, implementation, testing and documentation. An OpenAI image-generation tool produced an exploratory concept; the generated image is not included in the minimal public package. The shipped interface uses original code-native SVG equipment drawings and system fonts. It has no third-party runtime dependencies or bundled third-party assets.

Node.js, Git, Chrome and Playwright were development/test tools under their respective licenses and are not redistributed in this package. No existing third-party source notice was removed: none is present in the original app source. Installing optional tools remains subject to their own terms and licenses.

Public context: https://uwaterloo.ca/lib/services/equipment-loans informed the general hypothesis about short borrowing periods and location restrictions. Studio desk, inventory and policies are fictional. This is neither a campus service nor evidence of a defect in an existing service.
